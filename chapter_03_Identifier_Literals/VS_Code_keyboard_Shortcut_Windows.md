# Visual Studio Code Keyboard Shortcuts - Windows

This document contains the default keyboard shortcuts for Visual Studio Code on Windows.

## General Shortcuts

| Action | Shortcut |
|--------|----------|
| Command Palette | `Ctrl + Shift + P` |
| Quick Open (Go to File) | `Ctrl + P` |
| New Window | `Ctrl + Shift + N` |
| Close Window | `Ctrl + Shift + W` |
| Settings | `Ctrl + ,` |
| Keyboard Shortcuts | `Ctrl + K` `Ctrl + S` |

## Basic Editing

| Action | Shortcut |
|--------|----------|
| Cut line (empty selection) | `Ctrl + X` |
| Copy line (empty selection) | `Ctrl + C` |
| Move line up/down | `Alt + ↑` / `Alt + ↓` |
| Copy line up/down | `Shift + Alt + ↑` / `Shift + Alt + ↓` |
| Delete line | `Ctrl + Shift + K` |
| Insert line below | `Ctrl + Enter` |
| Insert line above | `Ctrl + Shift + Enter` |
| Jump to matching bracket | `Ctrl + Shift + \` |
| Indent/Outdent line | `Ctrl + ]` / `Ctrl + [` |
| Go to beginning/end of line | `Home` / `End` |
| Go to beginning/end of file | `Ctrl + Home` / `Ctrl + End` |
| Scroll line up/down | `Ctrl + ↑` / `Ctrl + ↓` |
| Scroll page up/down | `Ctrl + PageUp` / `Ctrl + PageDown` |
| Fold/unfold region | `Ctrl + Shift + [` / `Ctrl + Shift + ]` |
| Toggle line comment | `Ctrl + /` |
| Toggle block comment | `Shift + Alt + A` |

## Navigation

| Action | Shortcut |
|--------|----------|
| Go to File | `Ctrl + P` |
| Go to Symbol in File | `Ctrl + Shift + O` |
| Go to Symbol in Workspace | `Ctrl + T` |
| Go to Line/Column | `Ctrl + G` |
| Go to Definition | `F12` |
| Peek Definition | `Alt + F12` |
| Go to References | `Shift + F12` |
| Go Back / Forward | `Alt + ←` / `Alt + →` |
| Close Editor | `Ctrl + W` |
| Close All Editors | `Ctrl + K` `Ctrl + W` |

## Search

| Action | Shortcut |
|--------|----------|
| Find | `Ctrl + F` |
| Replace | `Ctrl + H` |
| Find in Files | `Ctrl + Shift + F` |
| Replace in Files | `Ctrl + Shift + H` |
| Next/Previous Match | `F3` / `Shift + F3` |

## Multi-cursor

| Action | Shortcut |
|--------|----------|
| Insert cursor above/below | `Ctrl + Alt + ↑` / `Ctrl + Alt + ↓` |
| Undo last cursor operation | `Ctrl + U` |
| Insert cursor at end of each line selected | `Shift + Alt + I` |
| Select current line | `Ctrl + L` |
| Select all occurrences of current selection | `Ctrl + Shift + L` |
| Select all occurrences of current word | `Ctrl + F2` |

| Toggle Sidebar Visibility | `Ctrl + B` |
| Toggle Panel | `Ctrl + J` |
| Toggle Terminal | `` Ctrl + ` `` |

## File

| Action | Shortcut |
|--------|----------|
| New File | `Ctrl + N` |
| Open File | `Ctrl + O` |
| Save | `Ctrl + S` |
| Save All | `Ctrl + K` `S` |
| Close File | `Ctrl + W` |

---

> **Tip:** You can view and customize all shortcuts in VS Code by pressing **`Ctrl + K`** then **`Ctrl + S`** (or go to **File > Preferences > Keyboard Shortcuts**).
